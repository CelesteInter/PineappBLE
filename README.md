# PineappBLE
PineappBLE - a CPS/IoT Security Project implimenting a dual process bluetooth low energy proxy and packet interceptor similar to a wifi pineapple. This project is developed for the Seeed ESP32S3.

## Initializing the project - ESP32S3

1. Use `VSCode` or IDE of choice that supports `Platform.io`
2. Install `Platform.io` extension
3. Clone this repository and open it in IDE
4. Initialize the project in `Platform.io` (open project)
5. Flash the board using Platform.io
